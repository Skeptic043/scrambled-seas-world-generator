Scrambled Seas World Generator

Make a Scrambled Seas world file at any size up to the whole globe, like the in-game world scale but bigger. Requires Border Expander.

Area limits (degrees)

The world never goes outside these. Longitude −180 to 180, latitude −70 to 70, at least 44° wide and 20° tall.

Scale
World scale

Keeps archipelagos further apart so they don't bunch up. Distances still vary.

Island spread

Up to 5.4x, which keeps every island inside the world bounds.

Seed

Share the seed and settings to share a world.

    Put the file in the folder that contains ScrambledSeas.dll, then load it from the Scrambled Seas menu when starting a new game.
