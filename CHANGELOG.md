# Changelog

## 1.1.0

### New
- Several scenario options to help define the type of world you want
- `More settings` for world shape, world centre, archipelago spacing and island spacing
- A `Reset to defaults` button under more settings
- The new `Show real positions` button for the preview shows the precise placements of islands with current settings
- `Copy link` shares the exact settings, and the file name includes the scenario

### Changed
- `Spread archipelagos out evenly` is now the top of the archipelago spacing slider
- World scale goes down to 0.5x
- World edges are rounded the same way as the in-game slider, so in-between scales such as 1.5x now match the game exactly

## 1.0.0

### Initial Release
- Make Scrambled Seas world files from 1x up to the whole globe, inside area limits you choose
